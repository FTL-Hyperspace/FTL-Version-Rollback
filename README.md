# FTL-Version-Rollback

A collection of patches used to rollback FTL: Faster Than Light to a version supported by [FTL Hyperspace](https://github.com/FTL-Hyperspace/FTL-Hyperspace)

## Supported rollbacks

**Windows**: 1.6.14, 1.6.22 -> 1.6.9

## How to use

1. Code > Download ZIP, then extract it.
2. Copy the contents into your FTL folder (where `FTLGame.exe` is).
3. Run `rollback.bat`.

The original `FTLGame.exe` is backed up as `FTLGame_orig.exe`. To undo, delete the patched `FTLGame.exe` and rename `FTLGame_orig.exe` back.
